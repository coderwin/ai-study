# MCP

MCP는 **Model Context Protocol**이다.  
AI에게 코딩을 시키지 않고, 미리 붙여 둔 도구로 외부 작업을 처리하기 위한 연결 표준이다.

## 사용 이유

- 코드 작업 없이, 말로 외부 작업(슬랙 보내기, 캘린더 기록 등)을 요청하고 처리한다.
- 클라이언트에 한 번 설정해 두면 그 안에서는 반복해서 쓸 수 있다.

“어디에서나”의 범위는 아래와 같다.

- 같은 Cursor에서 전역으로 켜 두면, 프로젝트·채팅이 바뀌어도 다시 쓸 수 있다.
- 다른 AI 앱이나 다른 PC에서는 같은 MCP 규격을 쓰지만, 그쪽에도 연결 설정은 한 번 해야 한다.
- 프로젝트 전용으로만 넣어 두면 그 폴더 안에서만 보인다.

한 줄로 쓰면 이렇다.

> MCP는 코딩 대신 말로 외부 일을 시키기 위한 것이고, 클라이언트에 한 번 붙여 두면 그 안에서는 계속 재사용한다.

## 한 줄 구조

```text
당신 → Cursor(AI) → MCP 도구 호출 → MCP 서버 → 외부 API/파일/DB
```

- **도구**: AI가 누르는 기능 버튼. 예) `메시지_보내기(채널, 내용)`
- **MCP 서버**: 그 버튼을 받아서 실제 Slack API 등을 치는 프로그램
- **로컬 MCP 서버**: 내 PC에서 Cursor가 띄우는 프로세스
- **실제 메시지**: Slack 회사 서버에 저장됨
